# Feedback Form

Веб-приложение обратной связи на Laravel. Форма позволяет пользователю
оставить обращение с контактными данными и сообщением. После серверной
валидации приложение формирует письмо с данными формы.

## Технологии

- PHP 8.3+
- Laravel 13
- Blade
- JavaScript
- CSS
- Vite
- Laravel Mail

## Возможности

- Адаптивная вёрстка формы обратной связи.
- Клиентская валидация обязательных полей.
- Серверная валидация с использованием Form Request.
- Проверка формата телефона и электронной почты.
- Ограничение длины полей: 255 и 4096 символов.
- Маска ввода российского номера телефона.
- Отправка формы через AJAX без перезагрузки страницы.
- Математическая CAPTCHA с проверкой ответа на сервере.
- Согласие на обработку персональных данных.
- Дополнительная защита от спама с помощью honeypot-поля
  и ограничения частоты запросов.
- Формирование HTML-письма с данными обращения через Laravel Mail.
- Обработка ошибок валидации и отправки письма.

## Требования

- PHP 8.3 или новее.
- Composer.
- Node.js и npm.
- PHP-расширения, необходимые Laravel 13.

База данных для работы приложения не требуется.

## Установка и запуск

Установите зависимости PHP:

```bash
composer install
```

Создайте файл окружения:

```bash
cp .env.example .env
```

Установите зависимости фронтенда:

```bash
npm install
```

Сгенерируйте ключ приложения:

```bash
php artisan key:generate
```

## Настройка окружения

В файле `.env` проверьте следующие параметры:

```dotenv
APP_NAME="Feedback Form"
APP_ENV=local
APP_DEBUG=true
APP_URL=http://127.0.0.1:8000

SESSION_DRIVER=file
CACHE_STORE=file
QUEUE_CONNECTION=sync

MAIL_MAILER=log
MAIL_FROM_ADDRESS="hello@example.com"
MAIL_FROM_NAME="${APP_NAME}"
```

Не заменяйте сгенерированный `APP_KEY` пустым значением.
Для локальной разработки используйте `APP_DEBUG=true`.
В production необходимо отключить отладку.

Очистите кэш конфигурации:

```bash
php artisan config:clear
```

Соберите фронтенд:

```bash
npm run build
```

Запустите сервер разработки:

```bash
php artisan serve
```

Откройте приложение в браузере:

http://127.0.0.1:8000

Миграции базы данных для работы приложения не требуются.

## Отправка электронной почты

По умолчанию используется `MAIL_MAILER=log`. В этом режиме Laravel
формирует письмо и записывает его содержимое в лог приложения.
Реальная доставка на электронную почту не выполняется.

Для отправки писем необходимо настроить почтовый транспорт в `.env`.
Например, для SMTP-сервера с портом 587:

```dotenv
MAIL_MAILER=smtp
MAIL_SCHEME=smtp
MAIL_HOST=<smtp-host>
MAIL_PORT=587
MAIL_USERNAME=<smtp-username>
MAIL_PASSWORD=<smtp-password>
MAIL_FROM_ADDRESS=<verified-sender-address>
MAIL_FROM_NAME="${APP_NAME}"
```

Замените значения на параметры вашего почтового провайдера.
Используйте подходящую схему шифрования и порт согласно его документации.
Не публикуйте SMTP-пароль и другие секреты в репозитории.

После изменения настроек выполните:

```bash
php artisan config:clear
```

Получателем письма является адрес, указанный пользователем в поле E-mail.


При использовании почтового драйвера `log` содержимое сформированных
писем можно найти в `storage/logs/laravel.log`.
